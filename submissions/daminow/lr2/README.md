## Допущения

Денежные правила взяты из учебного условия З-7. Названия состояний, дополнительные поля и интеграционные контракты являются проектным решением. Все суммы и интервалы в примерах — учебные допущения; они не характеризуют действующую систему.

Требуемые возможности интеграции: устойчивый ключ операции, чтение её результата, подтверждённый запрет позднего удержания и взаимоисключение физического приёма с отзывом регистрации. Если смежный API не даёт эти гарантии, автоматическое закрытие блокируется, а расхождение передаётся на разбор.
